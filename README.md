# R507 · Présentation de soutenance

Support de l'oral du projet **« Le Registre »** (R507, blockchain en 3D), dans le style du site : écran CRT, ville de nuit en Three.js, une chaîne de blocs qui s'allume au fil des diapos.

- Présentation : https://withren.github.io/R507-Pressoutenance/
- Site du projet : https://withren.github.io/R507-Blockchain/
- Dépôt du projet : https://github.com/withRen/R507-Blockchain

Un seul fichier, `index.html`, qui fonctionne aussi hors ligne (Three.js, polices et images embarqués).

## Commandes

| Touche | Action |
|---|---|
| F5 ou P | Présenter depuis le début (plein écran) |
| Maj+F5 | Présenter depuis la diapo actuelle |
| → ↓ Espace Entrée, clic | Diapo suivante |
| ← ↑ Retour | Diapo précédente |
| Début / Fin | Première / dernière |
| B | Écran noir |
| N | Notes de l'orateur |
| ? | Aide |
| Échap | Quitter la présentation |
